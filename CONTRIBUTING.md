# Contributing

Bug reports and pull requests are welcome.

- **Bugs**: open an issue with your distribution, GPU, headset, and `~/.cache/OpenDesk/streamer.log`.
- **Pull requests**: keep each one to a single change, and say how you tested it. Only the maintainer merges.
- **Builds**: there are no GitHub Actions. Run `tools/ci.sh linux` on your machine before opening a pull request.
  Release builds are made locally by the maintainer with `tools/release.sh`.
- **Please don't submit** a headset app or anything that replaces the official one, code taken from Virtual Desktop's
  applications, or support for its online servers.
